# Контракт запуска агента (run-log) — обязателен для всех агентов MYDON

Версия 1.0 · 04.07.2026 · Визуализация: `MYDON-Run-Inspector.html` (кнопка «Схема лога»).
Каждый запуск любого агента (cron или по событию) обязан породить ровно один
объект лога — в `runs.json` и в SQLite. Что не записано в лог — того не было.

## 1. Семь фаз (все обязательны, порядок фиксирован)

| Фаза | Что происходит | Статусы |
|---|---|---|
| INTAKE | Принять задачу, проверить полноту спеки и проверяемость DoD | ok / fail |
| PLAN | Записать understanding (как агент понял задачу своими словами) + план шагов, каждый шаг с тиром T0–T4 | ok / fail |
| CONTEXT | Собрать входы (KB, файлы, БД). Чего-то нет → пометка `[НЕТ В KB]`, warn | ok / warn / fail |
| EXECUTE | Выполнить шаги плана. Развилка с деньгами/риском → esc, не гадать | ok / warn / fail |
| VERIFY | Прогнать каждый пункт DoD с доказательством (pass/fail + evidence). Внешний чекер, не самооценка | okg / warn / skip |
| REPORT | RESULT: summary, assumptions, kb_gaps, recommendations | ok |
| LOG | Записать объект в runs.json + SQLite, обновить журнал агента | ok |

Правило: REPORT и LOG выполняются ВСЕГДА — даже при failed/blocked. Упавший
запуск без лога — двойная ошибка.

## 2. Статусы запуска

- `done` — все шаги, VERIFY все pass.
- `partial` — результат отдан, но ≥1 DoD fail (причина в evidence).
- `blocked` — развилка требует человека; эскалация отправлена; побочных эффектов нет.
- `failed` — выполнить нельзя (после ретраев); класс ошибки в RESULT; побочных эффектов нет.
- `running` — только для живого процесса.

## 3. Типы действий (actions)

`read` · `write` · `tg` (сообщение в Telegram) · `approve` (создана approval-карточка)
· `esc` (эскалация человеку с вариантами и рекомендацией) · `err` · `retry` · `git`.
Каждое действие с побочным эффектом (write/tg/approve) несёт тир (T1–T4).

## 4. Железные правила

1. **VERIFY — с доказательствами.** Каждый пункт DoD → `{pass, evidence}`.
   Evidence — конкретика: число, путь файла, id записи, § правила. «Всё ок» — не evidence.
2. **Эскалация вместо догадки.** Развилка, влияющая на деньги, качество или
   обязательства — `esc` с вариантами (1/2/3) и рекомендацией агента. Статус blocked.
   Пример-эталон: globerent-sales / мачта 4.8м.
3. **`[НЕТ В KB]` — это заявка, а не отговорка.** Отсутствующее знание фиксируется
   в `result.kb_gaps` + заявка в `kb/_requests/` для knowledge-curator. Работа
   продолжается без этого куска (partial), если он не блокирует деньги.
4. **Никаких побочных эффектов при blocked/failed.** Не создавать черновиков с
   неверной ценой, не слать полуготовые сообщения.
5. **Числа только с источником.** Каждое число в отчётах ссылается на файл/БД/URL.
6. **Ретраи: максимум 3, с backoff.** Класс ошибки в RESULT (`config` / `network` /
   `data` / `logic`). Платные вызовы — максимум 1 ретрай.
7. **Рекомендации вне scope — в `recommendations`,** не в самовольные действия.

## 5. Схема объекта (контракт для executor)

```json
{
  "id": "run-070308-ts01",
  "agent": "trend-scout",
  "status": "done | partial | blocked | failed | running",
  "attempt": 1, "started": "ISO8601", "finished": "ISO8601",
  "duration_s": 188, "tokens": 14200,
  "task": { "id": "TASK-01", "title": "...", "tier": "T2",
            "goal": "...", "dod": ["...", "..."] },
  "understanding": "как агент интерпретировал задачу",
  "plan": [{ "step": "...", "tier": "T1" }],
  "phases": [{ "name": "INTAKE..LOG", "s": "ok|okg|warn|fail|skip",
               "t": "08:00:04", "note": "..." }],
  "actions": [{ "t": "08:02", "type": "read|write|tg|approve|esc|err|retry|git",
                "text": "...", "tier": "T2" }],
  "files": [{ "path": "...", "op": "created|modified|read",
              "plus": 12, "minus": 3, "diff": "+строка\n-строка" }],
  "verify": [{ "dod": "...", "pass": true, "ev": "доказательство" }],
  "result": { "summary": "...", "assumptions": [], "kb_gaps": [],
              "recommendations": [] }
}
```

## 6. Метрики качества (KPI-строка Run Inspector)

- **first-pass rate** (done с 1-й попытки, VERIFY все pass): цель **>85%**.
- Эскалаций — норма, не провал: blocked-запуск с чистой эскалацией лучше
  «догадавшегося» done.
- kb_gaps — топливо для knowledge-curator и analyst-coach.
