# design-kit — грамматика командного центра MYDON для согласования

Самодостаточные HTML-превью визуальной грамматики панели, собранные на настоящих токенах
`apps/cc/src/app/globals.css` и компонентах `apps/cc/src`, — чтобы владелец согласовал вид до правки кода
(дизайн-волна `docs/AGENTIC_OS_ARMS_PLAN.md` §6.5). Кит не участвует в сборке панели и синхронизируется
в проект Claude Design через DesignSync; группа карточки задана первой строкой каждого файла
(`<!-- @dsCard group="…" -->`).

Открывается двойным щелчком по `index.html` — без сервера и без интернета: ни одного внешнего запроса,
только инлайн-CSS и инлайн-SVG, без JavaScript.
