# Чек-лист приёмки экрана

Пройти **перед** показом владельцу. Пункт не выполнен — экран не готов.

## Смысл
- [ ] Заголовок отвечает на вопрос «что это», `.lead` — «когда обновлено / откуда данные».
- [ ] Каждая плитка — вопрос владельца; клик ведёт к ответу. Числа без вопроса убраны.
- [ ] Пустое состояние говорит, что сделать. Ошибка Core показывает `CoreDown`, а не белый экран.
- [ ] Подписи русские; тиры — словами; термины — как в `memory/glossary.md`.

## Палитра и контраст
- [ ] Ни одного нового цвета вне токенов; `--agent` — только для ИИ-исполнителя.
- [ ] Оранжевая заливка — максимум одна на экран, поверх — тёмные чернила; белого на оранжевом нет.
- [ ] Текст ≥ 4,5:1, контролы и иконки состояний ≥ 3:1 — проверено в **обеих** темах (системная тёмная и `data-theme`).
- [ ] Новые классы объявлены так, что тема не «протекает» (цвета только через токены).
- [ ] Новый токен (если заведён) прошёл три условия `rules.md` §2: один смысл, числа контраста на карточке и на холсте в обеих ветках, носитель смысла кроме оттенка.

## Типографика
- [ ] Кириллица — Golos Text; цифры в таблицах и плитках — `.num`/`.mono` (табличные).
- [ ] Никаких `next/font/google`; новых шрифтов нет.

## Навигация и адаптив
- [ ] Ширина 390px: таббар виден, страница не скроллится вбок, таблицы — в `.table-scroll`.
- [ ] Ширина ≥ 900px: сайдбар, активный пункт один (`aria-current="page"`).
- [ ] Не глубже двух уровней навигации в поле зрения.
- [ ] Сетки агентского слоя: 1 колонка базовым правилом, 2 от `min-width: 720px`, 3 от `min-width: 1200px`; новые медиазапросы не спорят с 900px (сайдбар).

## Состояние на экране
- [ ] Каждое состояние несёт форму, слово и время; слово и класс берутся из `apps/cc/src/lib/state.ts`, второго словаря нет.
- [ ] Слово взято с ТОЙ ЖЕ оси, что вопрос экрана: занятость агента, здоровье источника, карточка агента и настройка системы — четыре разных оси.
- [ ] «В порядке» печатает ДАВНОСТЬ последней проверки — зелёная строка без времени приёмку не проходит, а абсолютный момент заставляет владельца вычитать его из шапки в уме.
- [ ] «Не оценить» без единого прогона печатает «не запускался», а не число дней.
- [ ] «Не запускался» стоит ТОЛЬКО там, где ядро это утверждает (`checksKnown: true`); там, где о проверках не известно, — нейтральное «когда проверяли — неизвестно».
- [ ] Строка со словами в узкой колонке проверена арифметикой на 390px: что осталось заголовку и куда уходит время.
- [ ] «Сломано» отличается весом 600 (не 700: он не загружен и синтезируется браузером).
- [ ] Левая полоса внимания — 3px и своим тоном (`--err` сломано, `--warn` молчит из-за поломки, `--hot` тревога бизнес-экрана); полоса и лампа «работает» не носят один тон; двух `border-left` на элементе нет.

## Формы (если есть мутации)
- [ ] `onSubmit` + `preventDefault` + `FormData` → server action в `startTransition`.
- [ ] При ошибке Core поля сохраняют ввод; при успехе — `router.refresh()`.
- [ ] Есть vitest-тест на сохранение ввода при ошибке (по образцу `customs-rates.test.tsx`).

## Код
- [ ] `pnpm --filter @mydon/cc typecheck && pnpm --filter @mydon/cc lint && pnpm --filter @mydon/cc test` — зелёные.
- [ ] Ветка и PR, не пуш в main.
- [ ] В `docs/decisions/` — запись, если экран меняет структуру навигации или правило дизайна.
